  │ Call: sbox_masked(i0, 0, i1, 0, ..., &o0_sh0,   │
  │                   &o0_sh1, ..., 0, 0, ..., 0)    │
  │ Output: o0_sh0 XOR o0_sh1, o1_sh0 XOR o1_sh1, ... 
  └──────────────────────────────────────────────────┘

  ✓ VERIFICATION: combined_output == golden_output?
